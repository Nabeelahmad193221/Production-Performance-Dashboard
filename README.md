# 🏭 Production Performance Dashboard | Power BI

## 📊 Project Overview

This project presents an interactive **Production Performance Dashboard** developed using Microsoft Power BI to monitor and analyze manufacturing production performance.

The dashboard provides insights into production targets, actual output, achievement percentages, production gaps, machine defects, first pass yield, and shift-wise performance.

It helps management identify production inefficiencies, monitor quality issues, and make data-driven business decisions.

## 🎯 Project Objectives

- Monitor planned vs actual production.
- Analyze production achievement across departments.
- Track machine-wise defects.
- Evaluate shift-wise production performance.
- Monitor rejection and rework quantities.
- Analyze First Pass Yield (FPY).
- Identify production gaps and performance trends.

## 📈 Dashboard Visualizations

1. **Daily Plan vs Actual:** Compares daily planned production with actual production.
2. **Achievement % by Department:** Evaluates production achievement across departments.
3. **Defect Split:** Analyzes rejection and rework quantities.
4. **Achievement % by Shift:** Compares production performance across shifts.
5. **Defect % by Machine:** Identifies machines contributing to production defects.
6. **Department × Shift Heatmap:** Compares department performance across different shifts.

## 🎛️ Interactive Filters

The dashboard includes the following slicers:

- Date
- Shift
- Department
- Machine
- Model

These filters allow users to explore production performance from different perspectives.
